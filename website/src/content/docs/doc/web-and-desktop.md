---
title: Web and desktop
description: What changes between Didi in a browser and the desktop app.
---

Didi is the same app in a browser and on the desktop, with the same tools.

## In a browser

- Your drawing is kept in the browser and comes back when you return. It is a copy, not a file: the browser can delete it, for example after some time without a visit, or when you clear your browsing data.
- **Ctrl+S** exports the drawing as a PNG image.
- Opening and saving `.didi` files in the browser is coming soon.

## Desktop app

The desktop app, for Windows and Linux, is not available for download yet.
