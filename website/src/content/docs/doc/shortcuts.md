---
title: Shortcuts
description: The keyboard shortcuts of Didi.
---

In the app, **Ctrl+/** shows this list, and the command palette (**Ctrl+K**) shows the shortcut of each command.

## General

| Shortcut               | Command         |
| ---------------------- | --------------- |
| Ctrl+K or Ctrl+Shift+P | Command palette |
| Ctrl+/                 | Shortcuts       |
| Ctrl+,                 | Preferences     |
| Ctrl+Z                 | Undo            |
| Ctrl+Shift+Z or Ctrl+Y | Redo            |

## Files

| Shortcut     | Command                              |
| ------------ | ------------------------------------ |
| Ctrl+N       | New                                  |
| Ctrl+O       | Open (desktop)                       |
| Ctrl+S       | Save (desktop), export PNG (browser) |
| Ctrl+Shift+S | Save as (desktop)                    |
| Ctrl+Shift+E | Export PNG                           |
| Ctrl+I       | Import image                         |

## Tools

| Key     | Tool or command          |
| ------- | ------------------------ |
| B or P  | Pixel brush              |
| E       | Pixel eraser             |
| G       | Paint bucket             |
| L       | Line                     |
| U       | Rectangle                |
| Shift+U | Ellipse                  |
| M       | Rectangle selection      |
| Q       | Lasso selection          |
| I       | Color picker             |
| X       | Swap colors              |
| ] and [ | Bigger and smaller brush |

## Selection and clipboard

| Shortcut               | Command            |
| ---------------------- | ------------------ |
| Ctrl+A                 | Select all         |
| Ctrl+D                 | Deselect           |
| Ctrl+Shift+I           | Invert selection   |
| Enter                  | Apply              |
| Esc                    | Cancel             |
| Ctrl+T                 | Transform          |
| Ctrl+X, Ctrl+C, Ctrl+V | Cut, copy, paste   |
| Ctrl+Shift+V           | Paste as new layer |
| Delete or Backspace    | Clear              |

## Layers and image

| Shortcut     | Command         |
| ------------ | --------------- |
| Ctrl+Shift+N | New layer       |
| Ctrl+J       | Duplicate layer |
| Ctrl+E       | Merge down      |
| Ctrl+Alt+C   | Canvas size     |
| Ctrl+Alt+I   | Image size      |

## View

| Key     | Command                |
| ------- | ---------------------- |
| 0       | Fit to window          |
| 1       | Actual size            |
| + and - | Zoom in and out        |
| 4 and 6 | Rotate left and right  |
| 5       | Reset rotation         |
| H       | Mirror view            |
| Ctrl+'  | Pixel grid             |
| Ctrl+B  | Show or hide panels    |
| Tab     | Hide or show interface |
| F11     | Full screen            |
