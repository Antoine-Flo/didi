# Didi

Logiciel de dessin pour tablette graphique, aussi à l'aise en pixel art qu'en peinture 2D, intégré à Godot.

## Démarrer

```
npm install
npm run tauri dev
```

Tests : `npm test` · Lint : `npm run lint` · Types : `npm run check`
